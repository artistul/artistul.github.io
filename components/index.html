01 / Operator

Control surface for supervised operation.

The InFlux Operator app presents machine status, supported commands, and servicing access. It is a prototype artifact and not a general-purpose machine controller.

02 / Motherboard

The control hub for machine behavior.

The Origin motherboard direction organizes sensors, outputs, and machine wiring around the Nucleo-owned control stack.

03 / Thermal Lab

Temperature data drives the design.

Thermal validation uses logged thermocouples, thermal-camera evidence, and simulation comparison to guide barrel, nozzle, insulation, and cooling choices.
