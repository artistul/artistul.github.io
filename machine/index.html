01 / Development path

The machine was built in evidence stages.

The project started from the question between 3D printing and industrial tooling: what can produce real thermoplastic parts without committing to expensive production equipment?

  • Sketch the injection process and isolate subsystems.
  • Define the machine structure, mold path, and injection axis.
  • Select components and integrate mechanics, electronics, firmware, and operator software.

02 / MK1 state

A supervised prototype, not a finished product.

MK1 is the first complete InFlux machine capable of producing real injected parts. It is still in calibration, and its current value is proof, measurement, and learning.

03 / Next direction

Repeatability is the next milestone.

The next version focuses on monitored automation, safer enclosure work, stronger process sensing, better mold life, and more complete validation data.
